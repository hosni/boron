# مرور کلی API

بورون لایه‌ای نازک از تقویم روی Carbon است. این نقاط ورود را ترجیح دهید:

| نوع | کاربرد |
|---|---|
| [`Boron\Carbon`](carbon.md) | تاریخ/زمان mutable (ارث از `Carbon\Carbon`) |
| [`Boron\CarbonImmutable`](carbon-immutable.md) | گونهٔ immutable |
| [`Boron\CarbonInterface`](carbon-interface.md) | type-hint برای Carbon آگاه از تقویم |
| [`Boron\CalendarDate`](calendar-date.md) | Y/M/D immutable در یک تقویم |
| [`Boron\CalendarRegistry`](calendar-registry.md) | جستجوی درایور، پیش‌فرض‌ها، ثبت |
| [درایورهای تقویم](calendar-drivers.md) | `CalendarInterface` و داخلی‌ها |

بقیه همان کربن است — به
[مستندات Carbon](https://carbon.nesbot.com/docs/) مراجعه کنید.
